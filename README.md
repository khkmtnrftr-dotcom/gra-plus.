# Лабораторія спрайтів

Практична робота демонструє векторного персонажа з чотирма станами: стояння, крокування, біг і стрибок. Спрайт створюється без зовнішніх файлів у Canvas, а кожен кадр має однаковий розмір 128 × 128 пікселів. Частота анімацій становить 5 FPS для стояння, 11 FPS для крокування, 15 FPS для бігу та 10 FPS для стрибка. Клавіші 1–4 перемикають стани, стрілки або A/D рухають героя, пробіл запускає стрибок, а H показує hitbox. Слайдер змінює масштаб від 60% до 160%, кнопка Flip віддзеркалює героя, а hitbox змінює форму й розміри залежно від анімації. Надалі можна додати імпорт власного спрайтшіта, більше напрямків руху та налаштування кадрів у редакторі. [Відкрити практичну на GitHub Pages](https://khkmtnrftr-dotcom.github.io/gra-plus./).
