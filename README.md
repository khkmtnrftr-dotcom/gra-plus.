# Гра+

Це невелика браузерна гра, у якій гравець збирає монети та уникає червоного ворога-переслідувача.  
Керування працює за допомогою клавіш WASD або стрілок, а на сенсорних екранах доступні екранні кнопки.  
Ворог рухається до гравця зі швидкістю 120 px/сек і стає на 10 px/сек швидшим за кожні 5 набраних очок.  
Дотик ворога до гравця завершує гру, після чого можна почати нову спробу.  
Під час збору монети відтворюється короткий звуковий ефект, створений засобами Web Audio API.  
Далі можна додати таблицю рекордів, бонуси, кілька типів ворогів і налаштування складності.  
Після публікації через GitHub Pages гра буде доступна за адресою `https://khkmtnrftr-dotcom.github.io/gra-plus./`.

## Публікація на GitHub Pages
1. Відкрий **Settings → Pages**.
2. У розділі **Build and deployment** вибери **Deploy from a branch**, гілку `main` і папку `/ (root)`.
3. Натисни **Save**; після завершення публікації GitHub покаже адресу сайту в цьому ж розділі.
