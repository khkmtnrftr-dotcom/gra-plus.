# Гра+ — Збирач монет

Гравець збирає монети на ігровому полі за допомогою клавіш WASD або стрілок, а раунд триває 60 секунд. Червоний ворог-переслідувач рухається зі швидкістю 120 px/с, і дотик до нього завершує гру. За кожні п’ять зібраних монет швидкість ворога збільшується на 10 px/с, а поточний рахунок, час і швидкість показані над полем. Під час збору монети відтворюється короткий звуковий сигнал, який можна вимкнути кнопкою. Після завершення раунду можна одразу почати нову гру. Далі гру можна розвинути, додавши рівні складності, рекорд і мобільне керування. Опублікована версія GitHub Pages: https://khkmtnrftr-dotcom.github.io/gra-plus./gra-plus/

## Запуск

Відкрийте `index.html` у сучасному браузері; для GitHub Pages завантажте `index.html`, `style.css`, `game.js` і цей README у корінь репозиторію та ввімкніть Pages для гілки `main`.
